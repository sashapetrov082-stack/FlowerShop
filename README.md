# Анисовый букет — лендинг

Одностраничный сайт цветочного салона в Коммунарке (ул. Александры Монаховой, 90к4).

Чистый HTML/CSS/JS без сборки: откройте `index.html` в браузере или разместите папку на любом статическом хостинге (GitHub Pages, Netlify, Яндекс Object Storage и т. п.).

## Структура

- `index.html` — разметка и тексты
- `css/style.css` — стили (цвета задаются переменными в `:root`)
- `js/main.js` — мобильное меню, просмотр фото, анимации появления
- `assets/img/` — фотографии, логотип (`logo.svg`) и иллюстрация Валеры (`valera.svg`)

## Как заменить фото

Положите новый файл в `assets/img/` и поменяйте путь в `index.html` (атрибуты `src` и `data-full` у карточки в блоке «Что мы собираем»).
